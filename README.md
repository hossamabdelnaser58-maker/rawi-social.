# راوي — Rawi

هذا المستودع يحتوي على تنفيذ الويب المستقل، وليس نسخة معاينة مساحة العمل. **الموقع غير منشور بعد، ولا توجد قاعدة إنتاج متصلة أو نسخة APK جاهزة.**

## ما يتضمنه الكود حاليًا

- تسجيل البريد الإلكتروني والدخول باستخدام Supabase Auth، وإعداد ملف شخصي.
- موجز منشورات نصية مع ترقيم بالوقت والمعرّف، وتعليقات وإعجابات، وحذف منشورات الحساب نفسه.
- واجهة عربية وإنجليزية، وتبديل اتجاه الصفحة والمظهر.
- ترحيل PostgreSQL يضيف الحسابات الخاصة والمتابعات والحظر وقواعد الوصول للمنشورات والتفاعلات. واجهة المتابعة والحظر ليست مضافة بعد.

## التشغيل والفحص

يلزم Node.js 22. انسخ `.env.example` إلى `.env.local` في بيئة التطوير، واضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` بقيم المشروع العامة. لا تضع مفتاح `service_role` أو كلمة سر قاعدة البيانات في متغيرات `VITE_` أو في Git.

```sh
npm install
npm run dev
npm run build
```

قبل تجربة البيانات الفعلية، طبّق ترحيلات `supabase/migrations` على مشروع اختبار بتفويض مناسب. اختبر بحسابين مستقلين خصوصية المنشورات قبل الموافقة على المتابعة وبعدها والحظر في الاتجاهين. تشغيل فحص GitHub لا يطبّق الترحيلات ولا يثبت صحة قواعد الوصول.

## Cloudflare Pages

إعدادات البناء المستهدفة: الفرع `main`، الأمر `npm run build`، المخرجات `dist`، والإصدار Node.js 22. يجب السماح لـCloudflare Pages بالوصول إلى هذا المستودع وإضافة قيم Supabase العامة في بيئة النشر. في Supabase Auth، اضبط رابط الموقع وروابط إعادة التوجيه المسموح بها على نطاق النشر الفعلي قبل اختبار تأكيد البريد. لا يوجد رابط تشغيل موثّق الآن.

## أندرويد

إعداد Capacitor يحدد الاسم `Rawi` ومعرّف الحزمة `com.rawi.social`. يدعم `Web build` تشغيل مهمة أندرويد اختياريًا؛ تتطلب خاصية أندرويد المتغيرين العامين للمشروع في GitHub، وتستهدف إخراج APK تجريبي غير موقّع بمفتاح إصدار. لم يجرِ توليد التطبيق الأصلي أو التحقق من مخرجات المهمة بعد.

## غير مكتمل للإطلاق

وسائط الصور والقصص، المحادثات الفورية، أدوات الاستكشاف، الإشعارات، الإشراف، اختبارات الصلاحيات والتفاعل على مشروع اختبار، والنشر العام ليست مكتملة. لا تستخدم هذا المستودع لإطلاق عام قبل إتمامها واختبارها.
